ФИНАЛЬНЫЙ ПРОМПТ ДЛЯ CLAUDE CODE

Работаем над библиотекой экранов PsyAssist.

Шаблон карточки утверждён. За основу принимаем вариант B (Balanced).

Никаких новых вариантов шаблона больше не создавать. Не менять
композицию. Не менять сетку. Не менять стиль. Работаем только внутри
утверждённого шаблона.

────────────────────────────────

ГЛАВНЫЙ ПРИНЦИП

Главный герой каждой карточки — реальный экран Telegram-бота PsyAssist.

Все остальные элементы существуют только для того, чтобы максимально
выгодно показать экран продукта.

Если возникает выбор между размером текста и размером экрана — всегда
увеличивать экран.

Экран никогда не уменьшается ради текста.

При вставке Telegram-скриншота:

• использовать максимально возможный масштаб; • показывать экран
полностью; • ничего не обрезать; • не добавлять лишние поля; • не
уменьшать изображение без необходимости; • экран должен занимать
максимально возможную площадь карточки без потери читаемости интерфейса.

────────────────────────────────

ПРОДУКТОВОЕ МЫШЛЕНИЕ

Не относись к задаче как к массовой генерации карточек.

Представь, что входишь в команду, создающую один из лучших AI-продуктов
для психологов.

Каждая карточка — самостоятельная продуктовая страница.

Она не продаёт функцию. Она показывает профессиональную ценность.

Перед созданием каждой карточки ответь себе:

1.  Какую профессиональную задачу решает этот экран?
2.  Что психолог сможет увидеть, понять, проверить или изменить
    благодаря этой функции?
3.  Почему без этой функции сделать это сложнее?
4.  Какой заголовок и текст лучше всего передают эту ценность?

Если нет уверенного ответа — не выдумывай.

────────────────────────────────

ЗАГОЛОВОК

• всегда одна строка; • никаких переносов; • короткий; • сильный; •
профессиональный; • без рекламы; • без слов: AI, бот, нейросеть,
алгоритм, функция, получите, используйте.

────────────────────────────────

ПОДЗАГОЛОВОК

Одно предложение. Максимум два.

Не описывает функцию. Не рекламирует продукт. Не использует слова
“AI-разбор”.

Объясняет, почему экран важен психологу.

────────────────────────────────

НИЖНИЙ БЛОК

Не использовать блок “Что получает психолог”.

Показывать профессиональный результат.

Каждый пункт отвечает на вопрос:

«Что изменится в работе психолога после использования этой функции?»

Использовать сильные профессиональные глаголы.

Не использовать рекламные конструкции.

────────────────────────────────

ТИПОГРАФИКА

Если нужно освободить место —

уменьшать:

• заголовок; • подзаголовок; • интервалы; • нижний текст.

Всё свободное пространство отдавать экрану Telegram.

────────────────────────────────

СТИЛЬ

Карточка должна выглядеть как продукт уровня:

Apple Notion Linear Raycast Arc Stripe

Не Canva. Не инфографика. Не рекламный баннер.

────────────────────────────────

ШАБЛОН ЗАФИКСИРОВАН

После утверждения запрещено менять:

• композицию; • сетку; • размеры; • типографику; • стиль; • расположение
элементов.

Менять можно только:

• заголовок; • подзаголовок; • нижний блок; • Telegram-скрин.

────────────────────────────────

ГЕНЕРАЦИЯ

После последних правок шаблона:

1.  Использовать его как единственный стандарт.

2.  Автоматически обработать все изображения из:

Product Media Kit/00_Original Screenshots/

Для каждого изображения:

• определить функцию; • придумать заголовок; • написать подзаголовок; •
сформулировать три профессиональных результата; • вставить
соответствующий Telegram-скрин; • экспортировать PNG в:

Product Media Kit/02_Final Cards/

Формат имён:

001_… 002_… 003_…

────────────────────────────────

ВАЖНО

Не придумывать назначение экранов.

Все тексты должны опираться только на реально изображённый экран.

Если назначение непонятно —

добавить экран в список:

«Требует ручной проверки»

и продолжить работу.

────────────────────────────────

РАЗНООБРАЗИЕ ЯЗЫКА

Избегать повторов.

Не использовать одинаковые заголовки.

Не повторять одинаковые конструкции.

Не использовать один и тот же глагол в соседних карточках.

Каждая карточка должна иметь собственный характер, оставаясь частью
единой системы.

────────────────────────────────

ФИНАЛЬНАЯ ПРОВЕРКА

После генерации всей библиотеки:

• проверить повторы; • проверить заголовки; • проверить подзаголовки; •
проверить глаголы; • проверить ощущение однообразия; • переписать слабые
карточки.

Главный критерий:

Если показать любую карточку опытному психологу без пояснений, она
должна сама вызывать интерес к соответствующей функции благодаря её
профессиональной ценности, а не рекламным обещаниям.

После завершения вывести отчёт:

• сколько карточек создано; • какие экраны пропущены; • найдены ли
дубликаты; • какие карточки были переработаны после редакторской
проверки.
