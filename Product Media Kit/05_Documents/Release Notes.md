# Release Notes — Product Media Kit

## v1 — первая библиотека экранов PsyAssist (2026-07-04)

- Собрана структура `Product Media Kit/` (`00_Original Screenshots`, `01_Working Layouts`, `02_Final Cards`, `03_Landing`, `04_App Store`, `05_Documents`).
- Создан и утверждён мастер-шаблон карточки (`01_Working Layouts/Card_Template.html`, вариант B «Balanced» из трёх протестированных вариантов) — 1080×1920, фиксированная композиция «заголовок → экран Telegram → нижний блок», без дальнейших изменений сетки и стиля.
- Собрана библиотека финальных карточек: **18 карточек** в `02_Final Cards/` (`001`–`018`).
- Утверждён и закреплён документально стандарт «заголовок = профессиональная задача, а не название экрана или функции» (см. `UX Principles.md`).
- Экран библиотеки сохранённых кейсов (карточка `006`) заменён и усилен: вместо короткого списка из 2–3 клиентов используется демонстрационный скриншот с 24 случаями; текст карточки полностью переписан вокруг идеи накопления практики в профессиональную базу знаний и интеллектуальный капитал психолога.
- Карточка `019_feedback_loop` исключена из основной библиотеки — перенесена в `02_Final Cards/_excluded/`, не удалена. Причина: доминирующее содержимое исходного скриншота дублирует экран карточки `001`, а не демонстрирует отдельную функцию обратной связи.
- Обнаружены и отдельно учтены (не входят в библиотеку экранов) восемь файлов в `02_Final Cards/` — коллажи и инфографика, подготовленные вручную для других целей, не по шаблону карточки (см. `Screen Library Index.md`).
- Финальные карточки библиотеки находятся в `Product Media Kit/02_Final Cards/`; полная документация — в `Product Media Kit/05_Documents/`.
