# Content Strategy — Product Media Kit

## Одна карточка = десятки материалов

Каждая финальная карточка библиотеки — не просто изображение, а контент-юнит PsyAssist: самостоятельная смысловая единица, которая может лечь в основу материалов для разных каналов без повторной проработки смысла.

Каждая карточка может использоваться как основа для:

- блока лендинга;
- статьи на B17;
- статьи в Дзен;
- поста в Telegram;
- поста во VK;
- коммерческого предложения;
- презентации;
- выступления;
- App Store / Google Play;
- FAQ;
- обучающего материала;
- портфолио.

## Принцип

Карточка никогда не создаётся только ради картинки. Она создаётся как единица знаний о продукте.

Поэтому каждая карточка должна быть достаточно самостоятельной, чтобы использоваться отдельно от остальных материалов — без обязательного контекста соседних карточек. Это прямое следствие стандарта `UX Principles.md`: если карточка отвечает на вопрос «какую профессиональную задачу решает этот раздел», она по определению закончена как смысловая единица и может жить отдельно в любом канале.

## Пример: карточка «Библиотека вашей практики» (006)

Одна карточка о накоплении кейсов в профессиональную базу знаний может стать основой для:

- статьи о том, как практика психолога превращается в профессиональную базу знаний;
- поста о накоплении интеллектуального капитала;
- блока лендинга про сохранённые кейсы;
- презентационного слайда о долгосрочной ценности PsyAssist;
- материала для B17 или Дзена.

## Как использовать этот документ

При планировании контента для конкретного канала — сначала смотреть `Screen Library Index.md` (колонка «Где использовать»), а не придумывать новый материал с нуля. Если подходящей карточки под канал/задачу нет — это повод добавить новую карточку по процессу из `Media Kit Guide.md`, а не писать текст в обход библиотеки.
