# Screen Library Index

Официальный индекс библиотеки экранов PsyAssist. Источник — `Product Media Kit/02_Final Cards/`. Обновлять при каждом добавлении, замене или исключении карточки (см. `Media Kit Guide.md`).

Всего карточек в основной библиотеке: **18**. Все — статус **Approved**.

Статус означает: `Approved` — прошла проверку по `UX Principles.md`, актуальна, используется как есть. `Draft` — текст или изображение ещё не утверждены. `Needs update` — требует пересмотра (найдено расхождение со стандартом или сменился скриншот). `Archived` / `Excluded` — не входит в текущую библиотеку, но сохранена.
