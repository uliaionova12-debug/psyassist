# Product Media Kit — PsyAssist

Product Media Kit — это не архив изображений, а единая библиотека визуальных и смысловых материалов PsyAssist.

Она нужна для того, чтобы продукт говорил единым языком во всех каналах:

- лендинг;
- App Store / Google Play;
- B17;
- Дзен;
- VK;
- Telegram;
- презентации;
- коммерческие предложения;
- выступления;
- портфолио.

Каждая финальная карточка — самостоятельная смысловая единица продукта: она показывает одну профессиональную задачу, которую решает PsyAssist, и может использоваться отдельно от остальных материалов в любом из перечисленных каналов (подробнее — `05_Documents/Content Strategy.md`).

Медиатека и документация визуальных материалов продукта PsyAssist. Рабочая версия — эта папка (`Product Media Kit/` в корне репозитория `psyassist`). Папка `public/product-media/` в этом же репозитории признана архивной и не используется до отдельного решения (см. `05_Documents/Release Notes.md`).

## Назначение

Здесь хранятся исходные скриншоты Telegram-бота PsyAssist, шаблон карточки, финальные карточки библиотеки экранов и материалы для лендинга/App Store. Библиотека карточек — основной актив папки: набор PNG-карточек 1080×1920, каждая из которых объясняет профессиональную задачу одного раздела PsyAssist психологу-практику.

## Структура папки

| Папка | Содержимое |
|---|---|
| `00_Original Screenshots/` | Исходные, необработанные скриншоты Telegram-бота. Источник для карточек. Не редактировать, не удалять. |
| `01_Working Layouts/` | Мастер-шаблон карточки (`Card_Template.html` / `.png`), логотип для карточек, черновые варианты (`Card_Template_Variants/`), техническое задание (`PsyAssist_Final_Card_Library_Prompt.txt`). |
| `02_Final Cards/` | Финальные, утверждённые карточки библиотеки экранов (001–018) — единственный источник правды для готовой библиотеки. Подпапка `_excluded/` — карточки, исключённые из основной библиотеки, но сохранённые для истории. |
| `03_Landing/` | Материалы для сайта-лендинга. |
| `04_App Store/` | Материалы для карточки приложения / App Store. |
| `05_Documents/` | Документация: индекс скриншотов, индекс библиотеки карточек, редакционные принципы, соглашение об именовании, инструкция по добавлению новых экранов, история версий. |

## Зачем эта медиатека существует

Product Media Kit — стратегический актив продукта, а не побочный результат дизайна. Библиотека карточек — это готовый набор смысловых материалов, из которых собираются лендинг, презентации, публикации на внешних площадках и коммерческие предложения, без повторной работы над смыслом с нуля каждый раз.

## Что считается рабочей медиатекой

Единственная рабочая медиатека проекта — эта папка, `Product Media Kit/`. Внутри неё единственный источник правды для готовых карточек — `02_Final Cards/` (без подпапки `_excluded/` и без посторонних файлов, см. `05_Documents/Screen Library Index.md`, раздел «Не входит в основную библиотеку»).

## Что нельзя удалять или перемещать без отдельного решения

- Ничего в `00_Original Screenshots/` — это единственные исходники, с них строятся все карточки.
- Утверждённый шаблон `01_Working Layouts/Card_Template.html` / `.png` — при любых изменениях сначала фиксировать причину в `05_Documents/Release Notes.md`.
- Файлы в `02_Final Cards/`, включая `_excluded/` — исключённые карточки не удаляются, а хранятся для возможного пересмотра.
- Любые PNG/HTML файлы библиотеки — перемещение или удаление обсуждается отдельно, не выполняется автоматически при обновлении документации.

Документация в `05_Documents/` может обновляться свободно по мере роста библиотеки — она описывает состояние, а не хранит исходные материалы.
